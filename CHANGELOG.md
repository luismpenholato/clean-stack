## [0.1.0] - 2026-07-11

### Added

- .NET 10 backend using Clean Architecture and CQRS.
- Angular 21 frontend with ng-zorro.
- React 19 and Next.js 16 frontend with Ant Design.
- Independent CI workflows for backend, Angular and React.
- Automated tests across the backend and both frontends.
- Docker support per application.
- Repository governance and contribution templates.
- GitHub Sponsors support.
- Documentation for setup, architecture and stack selection.
